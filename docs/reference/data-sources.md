# Data sources

Look here when a step or an option asks for a value you do not have yet: where it comes from and what uses it.
Options are those of `createCommunityLeader`, see [options](options.md); the constructor options are those of
`new SteamBadgeUnlocker(community, options)`.

| Data                                                     | Source                                                                                                                                                                                                                                                                                                                                                                                                                               | Used for                                                                                                                             |
|----------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| `username`, `password`                                   | your accounts; one row each in the accounts file of `examples/run-community-leader.js`                                                                                                                                                                                                                                                                                                                                               | login                                                                                                                                |
| `shared_secret`                                          | the Steam Mobile Authenticator data of the account, e.g. the `.maFile` of Steam Desktop Authenticator or your own authenticator export                                                                                                                                                                                                                                                                                               | `examples/utils/login-accounts.js` generates the login code with `steam-totp`; without it an account that asks for a code is skipped |
| refresh token                                            | written by `login-accounts.js` after the first login into `<accounts file>.tokens.json` (file mode 600), as `{"<username>": "<refreshToken>"}`; the `refreshToken` event of `steam-user` hands it out; a token that expires within the next hour is not used                                                                                                                                                                         | later logins without password                                                                                                        |
| master                                                   | one of your accounts: the first row of the accounts file, or the `masterInstance` option (its logged-in `steamcommunity` instance)                                                                                                                                                                                                                                                                                                   | friend quests, friend invite, friend's screenshot                                                                                    |
| `friendSteamId`                                          | SteamID64 (17 digits) of a friend, from `steamcommunity.com/profiles/<id>`; for a custom URL `steamcommunity.com/id/<name>`, the `steamID64` of `steamcommunity.com/id/<name>/?xml=1`; set to the master's SteamID when empty and `masterInstance` is set                                                                                                                                                                            | friend quests without a master                                                                                                       |
| `friendsScreenshotFileId`                                | the `id` in the URL of the friend's public screenshot, `steamcommunity.com/sharedfiles/filedetails/?id=<id>`; read from the master's newest screenshot when empty and the friend is the master                                                                                                                                                                                                                                       | PostCommentOnFriendsScreenshot, RateUpContentInActivityFeed                                                                          |
| `youtubeCookies.accessToken`                             | the `youtube_accesstoken` browser cookie after linking YouTube, see [How to get the YouTube cookie](../how-to/get-the-youtube-cookie.md); `YT_ACCESS_TOKEN` in `examples/run-community-leader.js`                                                                                                                                                                                                                                    | PostVideo                                                                                                                            |
| trading cards                                            | one full set of cards of any game in the account's inventory                                                                                                                                                                                                                                                                                                                                                                         | CraftGameBadge                                                                                                                       |
| profile background                                       | dropped by CraftGameBadge, or owned by the account                                                                                                                                                                                                                                                                                                                                                                                   | SetProfileBackground                                                                                                                 |
| Web API key                                              | not needed: quest progress is read from the badge page. An existing key (<https://steamcommunity.com/dev/apikey>) is found on its own while `fetchBadgesWithApiKey` is `true` (default); `steamcommunity` 3.48 and later only read an existing key, 3.43–3.47 register one for `localhost` when the account has none, so set `fetchBadgesWithApiKey: false` with those versions if you do not want that. Constructor option `apiKey` | quest progress                                                                                                                       |
| store `webapi_token`                                     | read automatically from the points shop page; constructor option `apiToken`                                                                                                                                                                                                                                                                                                                                                          | SetProfileBackground, `getOwnedProfileItems`                                                                                         |
| custom profile URL                                       | read from the account by `start()`; constructor option `customUrl`                                                                                                                                                                                                                                                                                                                                                                   | profile URL of the requests                                                                                                          |
| app, group, Workshop item, guide and other quest targets | [options](options.md#what-the-tasks-use)                                                                                                                                                                                                                                                                                                                                                                                             | the quest named in each option                                                                                                       |
